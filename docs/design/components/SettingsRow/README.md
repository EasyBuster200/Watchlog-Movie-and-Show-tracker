# SettingsRow

One row in a settings-style card. Label and sub on the left; on the right a chevron with an optional value (`kind="link"`), a Switch (`switch`), a small pill button (`button`), or a red pill button with a red label (`danger`). `badge` puts an accent count before the control; `disabled` dims the row. Stack rows inside a `bg-card` with `overflow: hidden`; the hairlines between them are drawn for you.

See `components/index.d.ts` for props.
